# CINEMATIC — веб-сервис отзывов о фильмах и сериалах

Учебный веб-проект на Node.js, Express, HTML, CSS, JavaScript и SQLite. SQLite подключается встроенным модулем `node:sqlite`: нативные дополнения, Python и node-gyp не нужны.

## Запуск на Windows
1. Установите Node.js 22.5 или новее (подойдёт установленный у вас Node.js 24).
2. Распакуйте архив и откройте папку `cinematic-review` в VS Code.
3. Откройте терминал именно в папке проекта.
4. Если обновляете старую папку проекта, удалите прежние `node_modules` и `package-lock.json` (если они есть). Выполните `npm install`.
5. Запустите `npm start`.
6. Откройте `http://localhost:3000`.

При первом запуске создаётся `data/cinematic.sqlite`. В базе находятся 40 фильмов и сериалов, более 110 персон и связи фильмографии. Существующая база автоматически дополняется новыми персонами и проектами при запуске. Чтобы сохранить старые отзывы, перенесите старый файл `data/cinematic.sqlite` в папку `data` нового проекта до первого запуска.

## Что реализовано
- Главная страница, тренды, новости, каталог с фильтрами и сортировкой.
- 40 фильмов и сериалов; вертикальные постеры 2:3.
- 110 актёров, режиссёров и актёров озвучки; роли указаны отдельно, фильмографии связаны с проектами.
- Страницы фильмов и сериалов, сезоны и серии, галерея кадров, похожие проекты.
- Отзывы, оценки, спойлеры, отметка полезности и комментарии.
- Регистрация и вход по логину/e-mail и паролю; пароль хранится как хеш scrypt.
- Публикация отзывов и комментариев, а также избранное/просмотренное доступны только после входа.
- Красивые всплывающие уведомления вместо системных alert/prompt.
- Новости с отдельными страницами, поиск, подборки, профили и фильмографии.

## Настоящие постеры, фотографии актёров и кадры из конкретного фильма
Для настоящих материалов используйте TMDB API. Без ключа сайт всё равно отображает локальные SVG-заглушки, чтобы не было пустых или сломанных блоков, но эти заглушки не являются фотографиями из фильмов.

1. Создайте аккаунт на https://www.themoviedb.org/.
2. Откройте https://www.themoviedb.org/settings/api и получите **API Key (v3 auth)**.
3. Скопируйте файл `.env.example` и назовите копию `.env`.
4. Откройте `.env` и вставьте ключ после `TMDB_API_KEY=`.
5. Выполните `npm install` (пакет `dotenv` уже указан в `package.json`).
6. Перезапустите сервер командой `npm start`.

После этого на странице проекта сервер ищет соответствующий фильм/сериал по названию и году, а затем получает его настоящий постер, фон, кадры, фотографии актёров и режиссёров. Если TMDB не находит совпадение или интернет недоступен, остаются локальные заглушки. Не публикуйте `.env` и не отправляйте API-ключ в открытый доступ.

## Структура
- `server.js` — Express-сервер, API, авторизация и интеграция TMDB.
- `db.js` — схема SQLite, миграции и демонстрационные данные.
- `public/index.html` — HTML-разметка.
- `public/css/styles.css` — оформление.
- `public/js/app.js` — клиентская логика.
- `data/cinematic.sqlite` — локальная база, создаётся автоматически.


## TMDB: исправление загрузки изображений
Для `TMDB_API_KEY` в `.env` используется именно **API Read Access Token** (длинный JWT-токен), который отправляется сервером в заголовке `Authorization: Bearer ...`. Не используйте v3 API Key вместо него в этом поле. Токен не вставляется в HTML или браузерный JavaScript.

После замены токена перезапустите сервер (`Ctrl+C`, затем `npm start`) и откройте страницу фильма заново. TMDB отдаёт относительные пути изображений; сервер собирает HTTPS-ссылки вида `https://image.tmdb.org/t/p/w500/...`. Если конкретный фильм не имеет постера или кадров в TMDB, сайт оставит локальную заглушку.
